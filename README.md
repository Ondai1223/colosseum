# マギアリーナ(旧コロッセウム)公開用リポジトリ
url: https://github.com/Ondai1223/colosseum.git

**ゲームジャンル**
3vs3のコマンドバトル

**メインシステム：** 魔素システム
キャラクターの攻撃などによって、属性がフィールド上のマス目に付与される。
同じマス目の中に付与された属性が2つ存在するとHPダメージやデバフなどの戦闘に有利な効果が発動される。
この属性の組み合わせによって、従来の『攻撃』と『防御』の駆け引きとは別に『属性』の駆け引きが生まれ、戦略性が生まれる

**私の役割:** クライアントエンジニア、サブリーダー</br>
**使用技術:** Unreal Engine 5, C++, Git/GitHub</br>
**開発期間:** 2025年9月〜現在 (7ヶ月以上継続中)</br>

### 2. 開発時の課題への対応と学習

| 項目 | 詳細 |
| :--- | :--- |
| **技術的課題** | Unreal Engineのガベージコレクションへの対応。メンバー変数に登録した配列の参照が失われ、配列内の要素がGCによって意図せず解放されてしまう事象に遭遇しました。 |
| **解決策** | 当該の配列を保持するメンバー変数に**`UPROPERTY()`マクロ**を付与し、GCの追跡対象に登録することで、参照が維持され、意図しない解放を防ぎました。 |
| **成長過程** | C++の**ポインタの概念**や**Unreal Engineの命名規則**など、学ぶことが多々ありましたが、この挑戦を通じて**ゲームの核となる機能を実装できる**レベルまで成長しました。 |

### 3. チームでの貢献と成長姿勢

このプロジェクトを通じて、**実践に近い形**でチーム開発を行うことができ、**現場で働くイメージ**を持つことができました。

* **主体的な学習:** 当初はUEやGitの知識が不足していましたが、「**調べてから考察を含めて質問する**」ことを徹底。プロのフィードバックを効率的に吸収し、短期間でコアロジックを任されるまでに成長しました。
* **初期タスク:** キャラクターの攻撃アクションの実装（`BattleActoin.cpp`など）を通じて、**先輩プログラマーのコードを基盤**に開発フローを習得。プロのコードを読むことで、設計のお手本をイメージできるようになりました。
