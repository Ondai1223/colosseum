Unit以下にhealer が追加されたので実装します。

・まず最初にhealer 以下に Charactor フォルダを追加します。
・Charactorの中に移動
　ブループリントの作成を選択し UnitModel を親に持つブループリントクラスを作成します。
　名前を
　　BP_UnitHealer1を作成
・ブループリントを開きます。
・ビューポートを選択
・ビューポートにUnit以下のhealer_P1 ドラックアンドドロップします。

コンポーネントが以下のようになっています。
   BP_UnitHealer1(self)
　　DefaultSceneRoot
     healer_P1

コンポーネントツリーの　healer_P1 を DefaultSceneRoot にドラックアンドドロップすると
   BP_UnitHealer1(self)
    healer_P1

という構造になります。

　これでキャラクタは完成です。

////////////////////////////////////////////////////////////////////////////////
	アニメーションの追加
////////////////////////////////////////////////////////////////////////////////

Animation フォルダを作ります。
Animation フォルダに入る
元となるモデルを入れる
「healer13.fbx」 で入れると問題があるので、名前をとりあえず「sk_healer.fbx」に変更
Animation フォルダにドラック＆ドロップ。インポートします。

続いてアニメーションをドラック＆ドロップ
sk_healer を元にしたアニメーションが入ります。

////////////////////////////////////////////////////////////////////////////////
	アニメーションブループリントの作成
////////////////////////////////////////////////////////////////////////////////
Animation フォルダに新規にAnimationBlueprints を追加 フォルダの中に入ります。

左ボタンメニューよりアニメーションブループリントを選択。
sk_healer_Skeletonを選択しアニメーションブループリントを作成、名前を「ABP_Healer」にします。

次に「Charactor」以下に作成した「UnitModel」を親に持つ「BP_UnitHeader1」「BP_UnitHeader2」をを開きます
左側にあるコンポーネントタグのツリー構造になっているところから「healer_P1」か「healer_P2」を選択します。
右側の詳細メニューよりアニメーションブループリントの設定をします。
Animationのカテゴリから「Animクラス」プルタグを押すと、ABP_Healer を選択できるようになっているのでそれを選択します。

ここまでで、キャラクタにアニメーションを設定する処理が完了。

次にステートマシーンの作成を行います。
ABP_Healer をダブルクリック。AnimGraphを開きます。
AnimeGprahで右ボタン検索バーにステートと入力します。
StateMachine っという項目がトップに出てくるのでそれを選択


次にアニメーションモンタージュの動作を入れるため
右ボタン、検索バーにSlot と入力、内番上にに Slot 'Default'が出てくるのでそれを選択します。

あとはこれをリンクします。ステートマシーンよりスロットへスロットより Output Pose につなげます。
これでアニメーションステートとアニメーションモンタージュの設定は完了です。


////////////////////////////////////////////////////////////////////////////////
	ステートマシーンとアニメーションモンタージュについて
////////////////////////////////////////////////////////////////////////////////
　この辺で理解に苦しむと思うので詳しく説明しておきます。


・ステートマシーン
　ステートマシーンはアニメーションの状態遷移を記すビンです。基本ループ再生するアニメーションを設定します。
　設置したらステートマシーンをダブルクリックすると中に入れて最初の状態「Empty」からスタートします。
　まず、待機アニメーションのIdle状態にしたいので「Empty」から線を引っ張って「Idle」を作ります。

　図解するとこんな感じです。

　Entry→Idle

　次にIdleでアニメーションを設定します。

　「Idle」をダブルクリック
　「Output Animation Pose」っというビンが表示されます。

　アセットブラウザからアニメーションさせたいアニメーションを選択しグラフにドラック＆ドロップします。
　すると「シーケンスプレーヤー」としてアニメーションのビンが作成されます。
　あとは、そのビンから「Output Animation Pose」に線でつなげます。
　アニメーションをループさせたい場合は詳細から「Loop Animation」にチェックを入れます。

　

・アニメーションモンタージュについて。
　ワンショットのアニメ（攻撃などの単発アニメ）

　モンタージュの作成
　任意のアニメーションを右ボタンでクリック、メニュー→作成する→「AnimMontargeを作成を選択」
　モンタージュで再生されるアニメだけ作成

　ヒーラーのブループリントを開く（BP_UnitHealer1、BP_UnitHealer2）

　UnitModel のイベントを作成

　ブループリントはアニメーションモンタージュ再生処理を書く
　BP_UnitHealer1 とか参照
